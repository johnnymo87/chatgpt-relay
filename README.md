# chatgpt-relay

CLI tool that sends prompts to ChatGPT via Playwright browser automation.

```bash
npm install
ask-question-login
ask-question "What is the capital of France?"
```

This repo uses `devenv`; opening a shell in the repo through `direnv` exposes
the local `ask-question*` commands without `npm link`.

See [CLAUDE.md](CLAUDE.md) for setup and usage.
